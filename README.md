# Batch-Renamer (Windows 10+ only, not tested on versions below win10)
My final-year university project, June 2022. Written in Python using built-in tkinter module. Major part finished exactly a year ago before GPT can write this (30/11/21).

# How To Use 

## For General Users
1. Download `batch-renamer-v3.4-stable.exe` to your device.
2. Simply launch it.

## For Advanced Users With Python Installed
1. Download `batch-renamer-v3.4-final with mark.py` to your device.
2. Simply launch it.
